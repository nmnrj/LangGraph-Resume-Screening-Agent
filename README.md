# LangGraph Resume Screening AI Agent

## Overview

An AI-powered Resume Screening Agent built using LangGraph and LangChain.

The agent:

- Categorizes candidate experience
- Assesses skill match
- Routes candidates using conditional logic
- Schedules HR interviews
- Rejects unsuitable candidates
- Demonstrates AI agent orchestration using LangGraph

## Tech Stack

- Python
- LangGraph
- LangChain
- GPT-OSS-20B (Groq)
- Google Colab

## Workflow

Resume
↓
Categorize Experience
↓
Assess Skill Match
↓
Conditional Routing
├── HR Interview
├── Recruiter Escalation
└── Rejection

## Concepts Used

- StateGraph
- TypedDict
- Nodes
- Edges
- Conditional Edges
- Prompt Templates
- Output Parsers
- AI Agent Workflow
